Record Collector — 시행일 2026년 10월 7일

Record Collector(이하 "서비스")는 개인이 운영하는 음반(CD·LP 등) 컬렉션 관리 웹사이트입니다. 이 문서는 서비스가 어떤 정보를 받고, 어디에 쓰고, 어떻게 지우는지 설명합니다.

1. 로그인하지 않고 쓰는 경우

로그인하지 않으면 입력한 음반 정보와 사진은 사용 중인 브라우저 안에만 저장되며 서비스 운영자에게 전송되지 않습니다. 브라우저 데이터를 지우면 함께 사라집니다.

2. 구글 계정으로 로그인하는 경우 받는 정보

항목쓰는 곳
구글 계정 이름 · 이메일 주소 · 계정 식별자로그인, 계정 구분, 관리자의 가입 승인
직접 입력한 음반 정보 (제목, 아티스트, 포맷, 연도, 장르, 곡 목록, 구매 정보, 평점, 메모 등)내 컬렉션 저장과 여러 기기 간 동기화
직접 올린 표지 사진음반 표지 표시
탑스터 보드 구성저장한 보드 다시 불러오기

구글 로그인으로는 이름·이메일·프로필 식별자만 받으며, 구글 계정의 다른 정보(연락처, 드라이브, 메일 등)에는 접근하지 않습니다.

3. 저장 위치

로그인한 사용자의 정보는 Supabase(대한민국 서울 리전)에 저장됩니다. 각 사용자는 자신의 데이터만 읽고 쓸 수 있도록 데이터베이스 수준에서 접근이 제한됩니다.

4. 공개 범위

  • 기본값은 비공개입니다.
  • 사용자가 직접 공개 프로필을 켜면, 정한 주소(/u/핸들)에서 다른 사람이 컬렉션을 볼 수 있습니다.
  • 공개 프로필에서도 가격 · 구매처 · 구매일 · 메모 · 이메일 주소는 표시되지 않습니다.

5. 제3자 제공 · 외부 서비스

받은 정보를 판매하거나 제3자에게 제공하지 않습니다. 다만 다음 기능을 쓸 때는 해당 서비스에 요청이 전송됩니다.

  • 음반 검색: 입력한 검색어가 Discogs 또는 Apple(iTunes) 검색 서비스로 전송됩니다. Discogs 토큰을 입력하지 않은 경우 Discogs 검색은 운영자의 중계 서버(Cloudflare)를 거칩니다.
  • 표지 이미지: Discogs · Apple 이미지 주소에서 직접 불러옵니다.
  • 사용자가 Discogs 개인 토큰을 입력한 경우, 토큰은 그 기기의 브라우저에만 저장되며 서비스 서버로 전송되지 않습니다.

6. 브라우저 저장소 · 접속 기록

로그인 상태 유지와 화면 설정(보기 방식 등)을 위해 브라우저 저장소(localStorage · IndexedDB)를 사용합니다. 광고·추적 목적의 쿠키는 쓰지 않습니다.

서비스를 제공하는 과정에서 호스팅(GitHub Pages), 데이터베이스(Supabase), 중계 서버(Cloudflare)가 접속 기록(IP 주소, 접속 시각 등)을 각 회사의 정책에 따라 남길 수 있습니다. 운영자는 이 기록을 서비스 운영과 오류 확인 외에 쓰지 않습니다.

7. 보관 기간과 삭제

  • 정보는 계정이 유지되는 동안 보관합니다.
  • 서비스 안에서 음반·사진을 지우면 즉시 삭제됩니다.
  • 계정과 모든 데이터의 삭제를 원하면 아래 연락처로 요청해 주세요. 확인 후 지체 없이 삭제합니다.
